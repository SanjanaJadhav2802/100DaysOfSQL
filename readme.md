# 💯 100 Days of SQL Challenge

This repository contains my solutions to the **100 Days of SQL Challenge** by Ankit Bansal (Udemy).

I am solving SQL problems daily to strengthen my understanding of database concepts, improve analytical thinking, and prepare for Data Analyst roles.

---

## 📌 About This Challenge

The goal of this challenge is to build strong SQL fundamentals through consistent practice and real-world problem solving.

Each file in this repository represents a daily SQL problem and its solution (e.g., Day1.sql, Day2.sql, etc.).

---

## 🛠 Skills Practiced

Throughout this challenge, I am practicing:

- SELECT statements  
- Filtering with WHERE  
- GROUP BY & HAVING  
- Joins (INNER, LEFT, RIGHT, FULL)  
- Subqueries  
- Common Table Expressions (CTEs)  
- Window Functions  
- Ranking Functions  
- Aggregate Functions  
- Date & String Functions  
- Query Optimization techniques  

---

## 🎯 Objective

- Strengthen SQL fundamentals  
- Improve problem-solving speed and accuracy  
- Build confidence for SQL interviews  
- Transition into a Data Analyst role
